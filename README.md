# Personal Portfolio Web Application

This repository contains the initial setup for a modern full stack personal portfolio application.

## Tech Stack

- Frontend: React + Vite, Tailwind CSS, React Router DOM, Axios
- Backend: Node.js, Express, MongoDB, Mongoose
- Authentication: JWT, bcrypt

## Project Layout

- `backend/` - Express API server with MVC architecture
- `frontend/` - Vite React application with Tailwind CSS

## Setup

1. Navigate to the backend or frontend folder.
2. Install dependencies with `npm install`.
3. Create `.env` files from `.env.example`.
4. Run backend with `npm run dev` and frontend with `npm run dev`.

## Notes

This repository currently contains only the project initialization and file structure. The next phase is to implement the full application logic, routes, and UI.
